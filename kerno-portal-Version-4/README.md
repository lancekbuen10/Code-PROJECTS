# Kerno Portal

Web portal for validating bills of materials, matching placement files, and generating feeder and device loading lists for electronics production.

**Languages:** Python, HTML, CSS, JavaScript. **Tools:** Django, Tailwind CSS, pandas, openpyxl, SQLite.

**Local setup:** Install `requirements.txt`, set the `DJANGO_SECRET_KEY` environment variable, then run `python manage.py migrate` and `python manage.py runserver`. The local database is excluded.
