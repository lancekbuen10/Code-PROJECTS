# MotorSiklo

Android companion app for a motorcycle violation detection system, with violation monitoring, ticket management, notifications, and statistics exports.

**Language:** Kotlin, with XML resources and Gradle Kotlin DSL. **Tools:** Jetpack Compose, Firebase, CameraX, ML Kit, and Gemini API.

**Local setup:** Open in Android Studio, supply your own `app/google-services.json`, and set `apiKey` in `local.properties`. Signing keys and build outputs are excluded. This folder contains the Android app; the separate detection backend is not included.
