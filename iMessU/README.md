# iMessU

A real-time Android chat app using Kotlin and Firebase.

**Role:** App Developer, UI and Logo Designer.

## Features

- Email and password registration and login.
- User list and one-to-one messaging.
- Real-time message updates through Firebase Realtime Database.
- XML screen layouts, app logo, and image assets.

## Open the project

1. Open this `iMessU` folder in Android Studio.
2. Set up a Firebase project with an Android app using package name `com.example.imessu`.
3. Enable Email/Password authentication and create a Realtime Database with appropriate access rules for your users.
4. Download your Firebase `google-services.json` and place it in `app/`.
5. Sync Gradle and run on an Android device or emulator with Android 7.0 (API 24) or later. The project uses compile SDK 34.

The original Firebase configuration, local SDK settings, IDE caches, and generated build files are excluded. Source code, layouts, logo assets, and the Gradle wrapper are included.
